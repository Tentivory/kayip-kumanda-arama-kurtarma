# KAYIP KUMANDA ARAMA-KURTARMA

**Kurum:** Tentivory Ulusal Koltuk Arası Teşkilatı (TUKAT)  
**Sınıf:** Resmi olmayan ama resmi görünen  
**Tehlike seviyesi:** Piller bitmek üzere

Bu depo, evrendeki en kadim kayıp eşya olan televizyon kumandasını arar. Bulmaz. Bulamaması da bir başarıdır, çünkü tutanak tutulmuştur.

## Neden var?

Çünkü kumanda koltuğun arasına düştüğü anda vatandaşlıktan çıkar, efsaneye girer. Bilim bunu ölçemez. Bu yazılım ölçer gibi yapar.

Operasyon bölgeleri:

- koltuk arası (birincil şüpheli, ikincil masum)
- yastık altı (muhalif bölge)
- sehpa çekmecesi (bürokrasi)
- buzdolabı üstü (kimse sormasın)
- kumandanın kendisinin üstü (ontolojik kriz)
- komşunun evi (diplomatik olay)

## Çalıştırma

```bash
python kumanda_kurtarma.py
python kumanda_kurtarma.py --oda salon --son-gorulen "koltuk sol minderi"
python kumanda_kurtarma.py --gizli
```

`--gizli` bayrağı protokol notunu açar. Açmamak da bir tercihtir. Tercih, pil gibidir: biter.

## Resmi garanti

Yazılım kumandayı bulmayı vaat etmez. Tutanak üretmeyi vaat eder. Tutanak, modern çağın en sağlam pilidir.
